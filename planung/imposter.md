# 🕵️ Imposter – Planung

Alle bekommen dasselbe geheime Wort – **außer dem Imposter**. Reihum sagt jede Person **ein Wort**, das zum
geheimen Wort passt. Die Crew muss den Imposter entlarven, der Imposter muss sich durchmogeln und am besten
noch das Wort erraten. Gespielt wird **einzeln**, mit **3–15 Personen**, auf einem herumgereichten Gerät oder
jede Person auf dem eigenen Handy.

## Überblick: 2 Modi × 2 Spielweisen

|                    | 📲 **Ein Gerät** (herumreichen)                       | 📱 **Jeder ein Handy**                              |
| ------------------ | ----------------------------------------------------- | -------------------------------------------------- |
| **🔤 Wort**         | Gerät zeigt jeder Person kurz ihr Wort, dann weiter   | Wort steht auf dem eigenen Handy, Abstimmung per Handy |
| **❓ Frage**        | wie links, Antworten werden laut gesagt              | Antworten werden getippt und gleichzeitig aufgedeckt |

Optional zeigt ein **Laptop/Fernseher als Bühne** Reihenfolge, Timer, Abstimmung und Punkte.

---

## 1. Modus „🔤 Wort“

### Ablauf einer Runde

| Phase              | Was passiert                                                                                  |
| ------------------ | --------------------------------------------------------------------------------------------- |
| **1. Verteilen**   | Alle sehen geheim ihr Wort (z. B. *Pizza*). Der Imposter sieht **„🕵️ Du bist der Imposter“** + optional die Kategorie (*Essen*). |
| **2. Hinweise**    | In zufälliger Reihenfolge sagt jede Person **ein Wort** (*„rund“*, *„Käse“*, *„Italien“* …). 1–3 Hinweisrunden. |
| **3. Diskussion**  | Wer war verdächtig? Timer (Standard 2 Minuten), vorzeitig beenden möglich.                     |
| **4. Abstimmung**  | Alle stimmen **gleichzeitig** ab (Handy oder Countdown 3 – 2 – 1 und auf jemanden zeigen).       |
| **5. Auflösung**   | Wer die meisten Stimmen hat, ist raus und wird aufgedeckt.                                     |
| **6. Letzte Chance** | War es der Imposter, darf er **das Wort raten**. Richtig → er klaut den Sieg.                 |

- **Gleichstand** bei der Abstimmung → kurze Stichwahl zwischen den Gleichen; wieder Gleichstand → niemand
  fliegt, der Imposter gewinnt.
- **Erste Person** in der Reihenfolge ist nie der Imposter (sonst hat er gar keine Hinweise gehört) –
  abschaltbar.
- Bei **2+ Imposters** (ab 7 Personen sinnvoll): Imposter kennen sich nicht. Abstimmung so lange, bis alle
  Imposter raus sind oder die Crew nicht mehr in der Überzahl ist (Variante „bis zum Ende“) – oder nur
  eine Abstimmung (Standard).

### Varianten

| Variante                | Imposter bekommt …                              | Weiß, dass er Imposter ist? |
| ----------------------- | ----------------------------------------------- | --------------------------- |
| **Klassisch** (Standard) | nichts / nur die Kategorie                      | ja                          |
| **Undercover**          | ein **ähnliches Wort** (*Tee* statt *Kaffee*)    | **nein** – findet es erst während der Hinweise heraus |

### Punkte (über mehrere Runden)

| Ereignis                                          | Punkte                       |
| ------------------------------------------------- | ---------------------------- |
| Imposter wird **nicht** erwischt                  | Imposter **+3**              |
| Imposter erwischt, **errät aber das Wort**        | Imposter **+2**              |
| Imposter erwischt und errät das Wort nicht        | Jede Crew-Person **+1**      |
| Für den Imposter gestimmt                          | diese Person **+1** extra    |

Gespielt wird eine feste Zahl Runden (Standard: so viele wie Personen, damit jede/r ungefähr einmal Imposter
ist – der Zufall verteilt fair, niemand zweimal hintereinander).

## 2. Modus „❓ Frage“

Statt eines Wortes bekommen alle eine **Frage**, der Imposter eine **andere Frage mit ähnlicher Art von
Antwort** – und weiß das nicht.

| Crew bekommt                              | Imposter bekommt                                 |
| ----------------------------------------- | ------------------------------------------------ |
| Wie viele Stunden schläfst du pro Nacht?  | Wie viele Stunden darf ein Kinofilm höchstens dauern? |
| Was ist dein Lieblingsessen?              | Was würdest du nie essen?                         |
| Wie viele Geschwister hättest du gern?    | Wie viele Haustiere hättest du gern?              |

1. Alle beantworten ihre Frage **gleichzeitig** (Handy) bzw. nacheinander laut.
2. Dann wird die **Crew-Frage** gezeigt, und alle sehen die Antworten nebeneinander.
3. Diskussion → Abstimmung → Auflösung wie oben (kein Wort-Raten).

## 3. Spielweisen

### 📲 Ein Gerät (Pass & Play)

- Namen eintragen → **„Gib das Gerät an Anna“** → Anna tippt auf **Aufdecken**, sieht ihr Wort,
  tippt auf **Verstanden** → Bildschirm wird wieder neutral → **„Gib das Gerät an Ben“** …
- Danach zeigt das Gerät Reihenfolge und Timer.
- Abstimmung: Countdown 3 – 2 – 1, alle zeigen auf jemanden, auf dem Gerät wird die Person mit den meisten
  Stimmen angetippt.
- Funktioniert **komplett offline**.

### 📱 Jeder ein Handy

- Eine Person erstellt den Raum (Handy **oder** Laptop), die anderen scannen den QR-Code.
- Jede Person sieht ihr Wort auf dem eigenen Handy, jederzeit wieder aufdeckbar (Antippen und halten).
- Reihenfolge, Timer und Abstimmung laufen auf allen Handys; Abstimmung geheim, Ergebnis gleichzeitig.
- Mit **Laptop als Bühne** zeigt dieser Reihenfolge, Timer, Abstimmungsergebnis und Punkte groß an.

**Host spielt mit:** Anders als bei 2 Dumme ist hier meist kein Laptop dabei – das Host-Handy spielt also selbst
mit. Es kennt technisch alle Wörter, zeigt sie aber nicht an. Unter Freunden reicht das.

## 4. Wörter & Fragen

- Ca. **400 Wörter** in Kategorien, jedes mit einem **ähnlichen Wort** für Undercover.
- Ca. **80 Fragen-Paare** für den Frage-Modus.
- Kategorien abwählbar, **18+**-Kategorie optional (wie in Activity).

Format (`js/words/woerter.js`): `Kategorie|Wort|ähnliches Wort` · Fragen (`js/words/fragen.js`): `Crew-Frage|Imposter-Frage`

## 7. Technische Umsetzung

### Ordner & Adresse

```
imposter/                       → https://tbnsuperkid.github.io/imposter/
  index.html, manifest.webmanifest, favicon.svg, sw.js
  css/style.css
  js/words/woerter.js           Wörter mit Kategorie + ähnlichem Wort
  js/words/fragen.js            Fragen-Paare
  js/engine.js                  Rollen verteilen, Reihenfolge, Phasen, Abstimmung, Wort raten, Punkte
  js/controllers.js             Ein Gerät / Host (Handy oder Laptop) / Mitspieler
  js/app.js                     Oberfläche
tests/imposter.test.js
```

### Architektur

- **Eine Engine für beide Spielweisen.** „Ein Gerät“ ist einfach ein Host ohne verbundene Geräte, der die
  Ansicht der Person zeigt, die gerade das Gerät hält.
- Rollen werden **nur auf dem Host** ausgelost. Jedes Handy bekommt in seiner gefilterten Ansicht nur
  **sein eigenes** Wort bzw. „Imposter“ – fremde Rollen erst bei der Auflösung.
- Wort raten nutzt den Wortvergleich aus 2 Dumme (`match.js` → nach `shared/` verschieben):
  *Pizzen* = *Pizza*, Tippfehler ok.
- Gemischte Rollen fair verteilen: Wer zuletzt Imposter war, wird für die nächste Runde ausgeschlossen;
  über das ganze Spiel wird gleichmäßig verteilt.
- **Spielzustand** (vereinfacht):
  ```js
  {
    settings: { mode: 'word' | 'question', input: 'pass' | 'phones', variant: 'classic' | 'undercover',
                imposters: 1, showCategory: true, clueRounds: 2, discussSec: 120, rounds: 6, categories: [...] },
    players: [{ id, name, score, connected }],
    round: 3,
    secret: { word: 'Pizza', category: 'Essen', decoy: 'Flammkuchen' },   // nur auf dem Host
    roles: { [playerId]: 'crew' | 'imposter' },                          // nur auf dem Host
    order: [playerId, …],
    phase: 'lobby' | 'reveal' | 'clues' | 'discuss' | 'vote' | 'runoff' | 'guess' | 'result' | 'end',
    seen: { [playerId]: true },                                          // Ein Gerät: wer hat schon geschaut
    votes: { [playerId]: playerId },
    answers: { [playerId]: '7' },                                        // Frage-Modus
    history: [ … ]
  }
  ```

### Tests

- Rollen: richtige Anzahl Imposter, nie zweimal hintereinander, erste Person nie Imposter (Option)
- Undercover: Imposter bekommt das ähnliche Wort und die Ansicht sieht wie eine Crew-Ansicht aus
- Abstimmung: Mehrheit, Stichwahl, doppelter Gleichstand → Imposter gewinnt, mehrere Imposter
- Wort raten mit Tippfehlern/Plural, Punkte laut Tabelle
- Gefilterte Ansicht: niemand sieht fremde Rollen oder das Wort, wenn er Imposter ist
- Wörterliste: jede Zeile hat Kategorie + Wort + ähnliches Wort, keine Dopplungen, Mindestanzahl je Kategorie

## 9. Offene Entscheidungen

1. **Standard-Spielweise:** Ein Gerät herumreichen oder jeder sein Handy? *Vorschlag:* Ein Gerät –
   so spielt man es meistens, und es geht ohne Internet.
2. **Darf der Host mitspielen** (Handy-Host kennt technisch alle Rollen)? *Vorschlag:* ja.
3. **Kategorie für den Imposter** standardmäßig zeigen? Macht es für Anfänger leichter.
4. **Punkte über mehrere Runden** oder nur „wer hat diese Runde gewonnen“? *Vorschlag:* Punkte, mit
   Siegerehrung am Ende wie bei den anderen Spielen.
