# 🔐 Codenames – Planung

Zwei Teams, **25 Wörter** auf dem Tisch. Nur die beiden **Geheimdienstchefs** wissen, welche Wörter zu
welchem Team gehören. Sie geben **ein Wort und eine Zahl** als Hinweis (*„Wasser, 3“*), ihr Team tippt auf die
passenden Karten – aber Vorsicht vor dem **Attentäter**. Der **Laptop** zeigt das Spielfeld für alle, die
Geheimdienstchefs sehen die **Schlüsselkarte auf ihrem Handy**.

## Überblick: 2 Spielweisen

|                     | 📲 **Nur Chef-Handys** (Standard)                         | 📱 **Alle mit Handy**                                |
| ------------------- | -------------------------------------------------------- | --------------------------------------------------- |
| **Spielfeld**        | Laptop / Fernseher                                       | Laptop + jedes Handy                                |
| **Schlüsselkarte**   | Chef-Handys per **QR-Code** – auch **ohne Internet**     | Chef-Handys im Raum                                 |
| **Hinweis**          | Chef sagt ihn laut                                       | Chef tippt ihn ein, erscheint groß auf dem Laptop    |
| **Karte wählen**     | Jemand aus dem Team klickt am Laptop                     | Team tippt auf dem Handy, Vorschläge sichtbar, einer bestätigt |

Dazu optional: **🍻 Trinkregeln** (siehe unten) und später der **Duett-Modus** für 2 Personen.

---

## 1. Regeln

### Aufbau

- **2 Teams** (🔴 Rot, 🔵 Blau), je mindestens 2 Personen: 1 Geheimdienstchef + Ermittler:innen.
- **25 Karten** (5×5) mit zufälligen Wörtern. Die geheime Schlüsselkarte legt fest:

| Karten | Gehören zu                              |
| ------ | --------------------------------------- |
| **9**  | Startteam (zufällig)                    |
| **8**  | anderes Team                            |
| **7**  | Unbeteiligte (neutral)                   |
| **1**  | ☠️ Attentäter                            |

### Ein Zug

1. Der Chef des Teams am Zug gibt einen Hinweis: **ein Wort + eine Zahl** (*„Wasser, 3“*).
   Das Wort darf **nicht auf dem Feld stehen** und kein Teil eines Feld-Wortes sein.
2. Das Team rät, tippt Karten nacheinander an – höchstens **Zahl + 1** Karten:
   - **Eigene Farbe** → aufgedeckt, darf weiter raten (oder freiwillig aufhören)
   - **Neutral** → Zug vorbei
   - **Gegnerfarbe** → Zug vorbei, die Karte zählt für den Gegner
   - **☠️ Attentäter** → Team **verliert sofort**
3. Gewonnen hat, wer **zuerst alle eigenen Karten** aufgedeckt hat.

Sonderhinweise (wie im Original erlaubt): **„0“** (*„nichts davon ist …“*, unbegrenzt raten) und
**„∞“** (beliebig viele Karten aus früheren Hinweisen).

### Mehrere Partien

- Eine **Partie** dauert ca. 10–15 Minuten. Gespielt wird **„Best of 3 / 5“** oder frei.
- Nach jeder Partie wechseln die **Geheimdienstchefs** reihum (App schlägt vor, wer dran ist).
- Optional **Sanduhr** pro Zug (Chef: 1–3 Min für den Hinweis, Team: 1–3 Min fürs Raten).

---

## 2. Spielweisen

### 📲 Nur Chef-Handys (Standard)

- Laptop zeigt das Feld + einen **QR-Code „Für Geheimdienstchefs“**.
- Der QR-Code enthält die **Schlüsselkarte selbst** (`codenames/#key=…`). Das Handy zeigt sie an,
  **ohne Raum, ohne Verbindung** – funktioniert auch offline, wenn die Seite einmal geladen war.
- Beide Chefs scannen denselben Code (sie sitzen nebeneinander auf einer Seite, wie im Brettspiel).
- Die Karten werden am Laptop angeklickt, die Schlüsselkarte auf dem Handy aktualisiert sich nicht
  (muss sie auch nicht – die Chefs sehen das Feld auf dem Laptop).
- *Notlösung ohne Handy:* Schlüsselkarte am Laptop kurz einblenden („Alle anderen wegschauen“). Unschön, aber geht.

### 📱 Alle mit Handy

- Raum + QR wie bei 2 Dumme, Teamwahl in der Lobby, pro Team wird ein Chef bestimmt.
- **Chef-Handy:** Feld mit Farben, Eingabe Hinweis + Zahl, Prüfung ob das Wort erlaubt ist.
- **Ermittler-Handys:** Feld ohne Farben. Antippen = **Vorschlag** (Name erscheint auf der Karte, auf dem Laptop
  auch). Zweites Antippen bzw. **„Aufdecken“** = festlegen. **„Zug beenden“**-Knopf.
- Laptop zeigt Feld, aktuellen Hinweis groß, Vorschläge, verbleibende Karten und die Sanduhr.

---

## 3. 🍻 Trinkregeln (optional)

Weil es auf der Trinkspiele-Liste steht: ein Schalter **„Trinkregeln“**, Standard aus.

| Ereignis                         | Wer trinkt                          |
| -------------------------------- | ----------------------------------- |
| Neutrale Karte erwischt          | Wer sie angetippt hat: 1 Schluck     |
| Gegnerkarte erwischt             | Ganzes Team: 1 Schluck               |
| ☠️ Attentäter                    | Ganzes Team: 3 Schlucke              |
| Hinweis für 3+ Karten komplett gelöst | Gegnerteam: 1 Schluck          |
| Partie verloren                  | Verliererteam: 1 Schluck pro übriger eigener Karte |

Die App zeigt nach jedem Ereignis eine kurze Einblendung („🔵 Blau-Wal: 1 Schluck 🍺“).
Alkoholfrei-Variante wie bei Piccolo: Strafpunkte statt Schlucke.

---

## 4. Wörter

- Ca. **400 Wörter**, bevorzugt **mehrdeutige** – das macht das Spiel aus:
  *Bank, Schloss, Kiefer, Leiter, Birne, Maus, Strauß, Hahn, Ball, Bauer, Mutter, Stift, Zug, Tor, Golf, Krone,
  Jaguar, Netz, Pilot, Wurm …*
- Nur Wörter, die man **ohne Erklärung** kennt, keine Eigennamen außer sehr bekannten (*Berlin, Mars*).
- Sets: **Standard**, **Kinder** (einfacher), **18+** (optional).
- Pro Spieleabend keine Wiederholung, solange genug Wörter übrig sind.
- Später: **🖼️ Bilder-Variante** mit Emojis statt Wörtern (🦁 🚀 🍄 …), gleiche Regeln.

Format (`js/words/woerter.js`): ein Wort pro Zeile.

## 7. Technische Umsetzung

### Ordner & Adresse

```
codenames/                      → https://tbnsuperkid.github.io/codenames/
  index.html, manifest.webmanifest, favicon.svg, sw.js
  css/style.css
  js/words/woerter.js, kinder.js, adult.js
  js/board.js                   Feld + Schlüsselkarte erzeugen, Schlüssel ↔ Link (#key=…)
  js/engine.js                  Züge, Hinweis prüfen, Aufdecken, Sieg/Niederlage, Partien, Trinkregeln
  js/controllers.js             Bühne (Laptop) / Chef (Handy) / Ermittler (Handy)
  js/app.js                     Oberfläche, inkl. reine Schlüssel-Ansicht
tests/codenames.test.js
```

### Architektur

- **Laptop = Host + Bühne**, wie bei 2 Dumme.
- **Schlüssel per Link** (Nur Chef-Handys): 25 Felder → 25 Zeichen `R`/`B`/`N`/`A` + Wörter-Seed, zusammen
  ca. 35 Zeichen im Link-Anker (`#…`, wird nie an einen Server geschickt). Das Handy zeigt daraus Schlüssel
  **und** Wörter, damit die Chefs zuordnen können. Keine Netzwerkverbindung nötig.
- **Alle mit Handy:** Rollen `spymaster` / `operative`. Gefilterte Ansicht: **Farben nur an Chefs**, Ermittler
  sehen nur aufgedeckte Farben. Aktionen: `join`, `clue`, `suggest`, `reveal`, `end-turn`.
- Hinweis prüfen: normalisieren (wie `match.js`), verboten wenn gleich einem Feld-Wort oder darin enthalten
  bzw. umgekehrt (*„Schloss“* ↔ *„Schlosspark“*).
- **Spielzustand** (vereinfacht):
  ```js
  {
    settings: { input: 'keys' | 'phones', match: 'free', chiefSec: 0, teamSec: 0, words: 'standard', drinks: 'off' },
    teams: [{ id: 'rot', name, wins: 1, chief: playerId, players: [...] }, { id: 'blau', … }],
    game: 2,                                     // Partie
    cards: [{ word: 'Bank', owner: 'rot' | 'blau' | 'neutral' | 'assassin', revealed: false, by: null }],
    starter: 'rot',
    turn: 'blau',
    clue: { word: 'Wasser', count: 3, left: 2 },
    suggestions: { [cardIndex]: [playerId] },
    phase: 'lobby' | 'clue' | 'guess' | 'game-over' | 'end',
    drinks: [{ team: 'blau', amount: 1, reason: 'neutral' }],
    history: [ … ]
  }
  ```

### Tests

- Feld: 25 verschiedene Wörter, 9/8/7/1, Startteam hat 9
- Schlüssel → Link → Schlüssel ergibt dasselbe, kaputter Link wird erkannt
- Züge: eigene Karte → weiter, neutral/gegnerisch → Wechsel, Attentäter → Niederlage, max. Zahl + 1,
  „0“ und „∞“, Sieg durch Gegnerfehler
- Hinweis prüfen: Feld-Wort, Teilwort, Plural, Groß/klein → abgelehnt
- Gefilterte Ansicht: Ermittler sehen keine ungeaufdeckten Farben
- Partien zählen, Chefs wechseln reihum, Trinkregeln laut Tabelle
- Wörterliste: keine Dopplungen, keine Wörter die Teil eines anderen sind (*Ball* / *Fußball*), Mindestanzahl

## 9. Offene Entscheidungen

1. **Name:** „Codenames“ ist eine Marke von Czech Games Edition. Hinweis wie bei Activity – oder eigener
   Name, z. B. **„Decknamen“**?
2. **Trinkspiel?** In den Ideen steht Codenames unter *Trinkspiele* – soll es ein normales Spiel mit
   optionalen Trinkregeln sein (Vorschlag) oder grundsätzlich als Trinkspiel gedacht?
3. **Standard-Spielweise:** Nur Chef-Handys (wie am Tisch, geht offline) oder alle mit Handy?
4. **Mehr als 2 Teams?** Das Original ist für 2 Teams; 3 Teams ginge (z. B. 7/6/6/5/1), macht das Feld aber
   unübersichtlich. *Vorschlag:* bei 2 bleiben.
