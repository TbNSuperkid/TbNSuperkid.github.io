# 🎨 Farbgefühl – Planung

Unsere Version von **Hues and Cues** (Scott Brady, The Op Games, 2020): Auf dem Bildschirm liegt eine
**Farbtafel mit 480 Farbtönen**. Eine Person sieht geheim eine Farbe und beschreibt sie mit **einem Wort** –
*„Avocado“*, *„Flamingo“*, *„Jeans“*. Alle anderen setzen einen Stein auf das Feld, das sie meinen.
Dann gibt es einen **zweiten Hinweis mit zwei Wörtern** und einen zweiten Stein. Aufgedeckt wird mit einem
**Rahmen**: Je näher dran, desto mehr Punkte – und die hinweisgebende Person punktet für jeden Stein im Rahmen.

Wie bei Pi mal Daumen ist ein **Laptop** (oder Fernseher) die **Bühne**: Er zeigt die große Farbtafel, die Steine
und das Aufdecken. Gespielt wird **mit Handys** (geheime Farbe + Tippen auf die Tafel) oder **mit einem Gerät**.

> Name: Wie bei Guess the word! / Geheimsache spielen wir nicht unter dem Markennamen. Arbeitstitel
> **Farbgefühl**, Ordner `farbgefuehl/` (Alternativen siehe offene Entscheidungen).

## Überblick: 2 Spielweisen

|                          | 🖥️ **Ein Gerät** (Laptop/Fernseher in der Mitte)            | 📱 **Mit Handys**                                           |
| ------------------------ | ---------------------------------------------------------- | ---------------------------------------------------------- |
| **Geheime Farbe**         | Bildschirm „Nur [Name] schauen!“ → Karte zeigen → verdecken | Erscheint nur auf dem Handy der hinweisgebenden Person      |
| **Hinweis**               | Wird laut gesagt (optional am Laptop eingetippt)            | Wird auf dem Handy getippt, App prüft verbotene Wörter      |
| **Steine setzen**         | Reihum am Laptop auf die Tafel klicken                      | Jede Person tippt auf dem eigenen Handy, Bühne zeigt es live |
| **Aufdecken & Punkte**    | Laptop                                                      | Laptop, Handys zeigen eigene Punkte + Vibration             |

- **3–10 Personen** einzeln, optional **Teams** (siehe Varianten)
- Jede Person ist **1× oder 2×** mit Hinweisgeben dran (siehe Spielende), danach **Siegerehrung**
- Passt gut zu unseren anderen Spielen: kein Wissen nötig, keine Texte/Fragen zu schreiben – der Aufwand steckt
  in der **Farbtafel** und der **Bedienung auf dem Handy**

## 1. Regeln (wie das Original)

### Material → digital

| Original                                      | Bei uns                                                         |
| --------------------------------------------- | --------------------------------------------------------------- |
| Spielbrett 30 × 16 = **480 Farbtöne**, Felder A1–P30 | Berechnete Farbtafel 30 Spalten × 16 Reihen (siehe Abschnitt 4) |
| **100 Karten** mit je 4 Farben + Koordinaten   | Zufallskarte mit 4 Farben aus verschiedenen Bereichen der Tafel  |
| 2–3 Kegel pro Person in eigener Farbe         | 2 Steine pro Person und Runde (Spielerfarbe + Initiale)         |
| Wertungsrahmen 3 × 3                          | Animierter Rahmen beim Aufdecken                                |
| Punkteleiste am Brettrand                     | Punktetafel / Rangliste                                         |

### Ablauf einer Runde

1. **Karte ziehen:** Die hinweisgebende Person bekommt **4 Farben** und wählt geheim **eine** davon.
2. **Hinweis 1 – ein Wort.** Verboten:
   - **Grundfarben-Namen** (rot, blau, grün, gelb, orange, lila, pink, braun, schwarz, weiß, grau …)
   - **„hell“ / „dunkel“** und Zusammensetzungen damit
   - **Dinge im Raum** („wie Annas Pulli“), **Koordinaten** („B12“), schon **benutzte Hinweise**
   - Erlaubt sind seltenere Farbnamen (*Bordeaux*, *Türkis*, *Ocker*) und alles Bildhafte (*Avocado*, *Rost*)
3. **Steine setzen, Runde 1:** Reihum **im Uhrzeigersinn** ab der hinweisgebenden Person setzt jede Person
   **einen Stein** auf ein **freies Feld** (ein Stein pro Feld – wer später dran ist, hat Pech oder kann taktisch
   daneben setzen).
4. **Hinweis 2 – ein oder zwei Wörter** (gleiche Verbote). Die hinweisgebende Person darf auch **verzichten**
   (wenn die Steine schon gut liegen, lohnt sich das).
5. **Steine setzen, Runde 2:** jetzt **gegen den Uhrzeigersinn**, wieder ein Stein pro Person.
6. **Aufdecken:** Die Zielfarbe wird gezeigt, der **Rahmen** legt sich darum, Punkte werden verteilt.

### Punkte

Abstand = Felder in jede Richtung, **diagonal zählt wie gerade** (Schachkönig-Abstand):

```
   1  1  1  1  1
   1  2  2  2  1          3 = genau die Farbe
   1  2 [3] 2  1          2 = im Rahmen (direkt daneben, auch diagonal)
   1  2  2  2  1          1 = direkt am Rahmen außen
   1  1  1  1  1          0 = weiter weg
```

| Wer                      | Punkte                                                                        |
| ------------------------ | ----------------------------------------------------------------------------- |
| Ratende (pro Stein)      | **3 / 2 / 1 / 0** wie oben – beide Steine zählen einzeln                       |
| Hinweisgebende Person    | **1 Punkt pro Stein im 3 × 3-Rahmen** (also 3er und 2er, max. 9)               |

Am Rand der Tafel wird der Rahmen einfach abgeschnitten.

### Spielende

| Personen | Original                         | Bei uns (Standard)              |
| -------- | -------------------------------- | ------------------------------- |
| 3–6      | jede Person **2×** Hinweisgeben   | 2 Durchgänge                    |
| 7–10     | jede Person **1×**                | 1 Durchgang                     |

Einstellbar: 1 / 2 / 3 Durchgänge oder **„Bis 50 Punkte“** (Variante aus der Anleitung). Bei Gleichstand an der
Spitze: **Stechen** – eine Extra-Runde, in der die App die Hinweise reihum vergibt.

## 2. Spielweisen

### 🖥️ Ein Gerät

- Namen + Spielerfarbe eintragen (3–10), Reihenfolge = Sitzordnung (per Ziehen änderbar, wichtig für
  Uhrzeigersinn / Gegenuhrzeigersinn).
- **Geheime Karte:** Laptop zeigt *„🙈 Alle wegschauen – nur Ben!“* → Ben tippt *„Zeigen“* → 4 Farben, er klickt eine an
  → *„Verdecken“*. Die gewählte Farbe bleibt danach unsichtbar (auch nicht über Zurück-Taste).
- Ben sagt den Hinweis laut. Optional tippt er ihn ein, dann steht er groß über der Tafel und die App prüft Verbote.
- **Steine setzen:** Oben steht *„Anna ist dran“*; sie klickt auf die Tafel → Vorschau mit **Lupe** (Ausschnitt
  vergrößert) → Klick noch mal = setzen. Rückgängig für den letzten Stein.
- Funktioniert auch mit **Fernseher + Maus** oder einem Tablet in der Mitte.

### 📱 Mit Handys

- Laptop zeigt QR-Code, alle treten mit Namen bei und wählen eine Spielerfarbe.
- **Hinweisgeben auf dem Handy:** 4 Farbkarten groß, eine antippen → Textfeld für den Hinweis → *Senden*.
  Die App warnt bei verbotenen Wörtern (siehe Abschnitt 3) – „trotzdem senden“ ist möglich, die Runde entscheidet.
- **Raten auf dem Handy:** Handy zeigt die ganze Tafel **im Querformat** (Hinweis: „Handy drehen“).
  30 Spalten sind auf dem Handy klein (~20 px pro Feld), deshalb:
  1. Tippen → **Lupe** mit 7 × 7-Ausschnitt um die Stelle, große Felder
  2. In der Lupe genau tippen oder mit Pfeilen verschieben → **Setzen ✓**
- Belegte Felder sind auf dem Handy gesperrt; die **Bühne zeigt jeden Stein live**, sobald er gesetzt wird.
- Wer nicht dran ist, sieht auf dem Handy *„Cem setzt gerade …“* und die Tafel mit allen Steinen.
- Das erste verbundene Handy ist (wie bei Pi mal Daumen) die **Spielleitung** und kann weiterschalten.
- Wiederverbinden/Abwarten bei Verbindungsabbruch wie in den anderen Spielen über `shared/room.js`.

### Reihum oder gleichzeitig?

| Modus                    | Ablauf                                                     | Für wen                                 |
| ------------------------ | ---------------------------------------------------------- | --------------------------------------- |
| **Reihum** (Original)     | Einer nach dem anderen, ein Stein pro Feld                  | Standard – das Blockieren ist Taktik    |
| **Gleichzeitig** (Schnell)| Alle setzen gleichzeitig geheim, mehrere Steine pro Feld erlaubt, Bühne deckt gemeinsam auf | große Runden, nur mit Handys |

## 3. Hinweis-Prüfung (nur wenn eingetippt)

- Normalisieren mit `shared/match.js` (`normalize`), dann prüfen:
  - Liste **verbotener Wortteile**: `rot, blau, gruen, gelb, orange, lila, violett, pink, rosa, braun, schwarz,
    weiss, grau, hell, dunkel` → greift auch in *„Himmelblau“*, *„Dunkelrot“* (Absicht: so sind die Regeln)
  - Ausnahmen-Liste für Wörter, die nur zufällig so enthalten sind (*Brot*, *Karotte*, *Grauen*? → Runde
    entscheidet; Liste klein halten, lieber Warnung als Verbot)
  - **Koordinaten-Muster** (`A1`–`P30`), Zahlen
  - Hinweis 1: genau **ein Wort**; Hinweis 2: **ein oder zwei Wörter** oder leer (= verzichten)
  - **Schon benutzt** in diesem Spiel (über `guessMatches`, also auch Plural/Tippfehler)
- Ergebnis ist immer nur eine **Warnung** mit Grund (*„‚Dunkel‘ ist verboten“*) und *„Trotzdem senden“* –
  die Runde hat das letzte Wort, die App ist kein Schiedsrichter.

## 4. Die Farbtafel 🌈 (Kernstück)

Das Original-Brett können (und wollen) wir nicht kopieren – wir **berechnen** eine eigene Tafel.
Ziel: benachbarte Felder sehen **gleich weit voneinander entfernt** aus, sonst ist das Raten unfair.

- Farbraum **OKLCH** (wahrnehmungsgleich): Spalten = **Farbton** einmal rundherum (30 Spalten à 12°),
  Reihen = **hell → dunkel** (16 Stufen), Sättigung am Rand etwas zurückgenommen (wie im Original:
  oben pastell, Mitte kräftig, unten tief).
- Umrechnung OKLCH → sRGB-Hex **in JS** (kleine Formel, keine Bibliothek), Farben außerhalb des Bildschirm-Farbraums
  werden durch Verringern der Sättigung zurückgeholt. Die 480 Hex-Werte werden einmal beim Laden berechnet –
  Laptop und Handy rechnen **exakt dieselben** Werte.
- Feste Tafel (keine Zufallstafel), damit man mit der Zeit ein Gefühl bekommt. Die Formel liegt in `js/board.js`
  und wird mit einem Test abgesichert (480 Felder, alle gültige Hex-Werte, keine Doppelten, Nachbarn ähnlich).
- **Koordinaten** A–P (Reihen) und 1–30 (Spalten) am Rand – klein und dezent, damit niemand „nach Zahlen“ rät;
  abschaltbar.
- **Geheime Karte:** 4 Farben aus 4 verschiedenen Vierteln der Tafel, mindestens 5 Felder Abstand zueinander.
  Schon gezogene Zielfarben werden bis zum Spielende nicht wiederholt (wie `deck.js` bei Pi mal Daumen).
- **Bildschirm-Problem:** Jedes Display zeigt Farben etwas anders, Handys im Nachtmodus (Blaufilter, True Tone)
  verfälschen stark. Deshalb: beim Beitreten der Hinweis *„🌙 Nachtmodus/Blaulichtfilter aus, Helligkeit hoch“*.
  Entscheidend ist immer die **Bühne** – auf dem Handy wird zum Zielen getippt, geschaut wird auf den Laptop.
- **Farbsehschwäche:** Option „Koordinaten in jedem Feld“ und beim Hinweisgeben auf Wunsch die Koordinate
  anzeigen. Das Spiel bleibt schwer, aber spielbar.

## 8. Technische Umsetzung

### Ordner & Adresse

```
farbgefuehl/                    → https://tbnsuperkid.github.io/farbgefuehl/
  index.html, manifest.webmanifest, favicon.svg, sw.js
  css/style.css
  js/board.js                   Farbtafel berechnen (OKLCH → Hex), Koordinaten A1–P30, Abstand
  js/cards.js                   4 Zielfarben ziehen (verschiedene Bereiche, ohne Wiederholung)
  js/cues.js                    Hinweis-Prüfung (Grundfarben, hell/dunkel, Koordinaten, schon benutzt)
  js/engine.js                  Personen, Reihenfolge, Phasen, Steine, Wertung, Spielende, Ansichten
  js/controllers.js             GameRoom.create({ game: 'farbgefuehl', net: 'farbgefuehl-v1-', storage: 'farbgefuehl', engine })
  js/app.js                     Oberfläche: Tafel (Canvas), Lupe, Aufdecken-Animation
tests/farbgefuehl.test.js
```

Dazu wie immer: Karte in der Start-`index.html`, Ordner bei `PUBLIC_DIRS` in `server/server.js`,
Test in `package.json` → `npm test`, README-Abschnitt + Zeile in der Spieletabelle.

### Architektur

- **Laptop = Host + Bühne**, Handys schicken nur `join`, `pick` (Zielfarbe wählen), `cue` (Hinweis), `place`
  (Stein setzen), `skip` (auf Hinweis 2 verzichten), `next` (Spielleitung).
- Die Engine passt zum Muster aus `shared/room.js` (`connect`, `disconnect`, `apply`, `viewFor` …) wie bei
  Pi mal Daumen.
- **`viewFor(pid)`** verrät die Zielfarbe und die 4 Kartenfarben **nur** der hinweisgebenden Person – allen anderen
  erst nach dem Aufdecken. Die Bühnen-Ansicht kennt die Zielfarbe ebenfalls nicht, bis aufgedeckt wird
  (sonst sieht man es im Entwickler-Werkzeug / auf dem Fernseher).
- Bei **Ein Gerät** läuft dieselbe Engine lokal ohne Raum; „verdecken“ ist reine Oberfläche.
- Tafel als **`<canvas>`** (480 Felder + Steine, flüssige Lupe und Rahmen-Animation), Klick → Feld per Rechnung.
  Steine als kleine Kreise in Spielerfarbe mit Initiale, mit dunklem Rand, damit sie auf jeder Farbe sichtbar sind.
- Sounds & Konfetti aus `shared/fx.js` (Plopp beim Setzen, Trommelwirbel beim Rahmen, Fanfare beim Volltreffer).
- **Spielzustand** (vereinfacht):
  ```js
  {
    settings: { input: 'single' | 'phones', order: 'turns' | 'simultaneous', rounds: 2 | 'auto' | 'to50',
                secondCue: true, cueCheck: true, coords: 'edge', timer: 0, teams: 0, freePick: false, blind: false },
    players: [{ id, name, color: '#f97316', score: 14, stats: { bullseyes: 2, giverPoints: 9 }, connected }],
    seats: ['p1', 'p2', 'p3', 'p4'],                 // Sitzordnung für Uhrzeigersinn
    turn: 5, giver: 'p2',
    card: [{ r: 7, c: 9 }, { r: 2, c: 21 }, …],       // 4 Kartenfarben (nur für giver sichtbar)
    target: { r: 7, c: 10 },                          // gewählte Zielfarbe (geheim)
    cues: ['Avocado', 'reife Schale'],
    usedCues: ['Avocado', 'Flamingo', …],
    stones: [{ pid: 'p1', round: 1, r: 8, c: 11 }, …],
    current: 'p3',                                    // wer gerade setzt (Reihum)
    phase: 'lobby' | 'pick' | 'cue1' | 'place1' | 'cue2' | 'place2' | 'reveal' | 'scores' | 'tiebreak' | 'end',
    usedTargets: ['H10', 'B22', …],
    history: [{ giver, target, cues, points: { p1: 2, p3: 3, p2: 4 } }]
  }
  ```

### Tests

- Tafel: 480 Felder, gültige Hex-Werte, keine zwei gleichen, Nachbarn ähnlicher als weit entfernte Felder
- Koordinaten: `A1` ↔ `{ r: 0, c: 0 }`, `P30` ↔ `{ r: 15, c: 29 }`, ungültige Eingaben
- Wertung: Abstand 0/1/2/3 → 3/2/1/0, diagonal zählt, Rand der Tafel, Hinweisgeber 1 Punkt pro Stein im 3 × 3
- Setzen: Reihenfolge Uhrzeigersinn ab Hinweisgeber, Runde 2 gegen den Uhrzeigersinn, belegtes Feld abgelehnt,
  Hinweisgeber setzt nicht, Gleichzeitig-Modus erlaubt mehrere Steine pro Feld
- Hinweis-Prüfung: *Dunkelrot* / *himmelblau* / *B12* / zwei Wörter bei Hinweis 1 / schon benutzt → Warnung;
  *Avocado*, *Bordeaux* → ok
- Spielende: 3–6 Personen 2 Durchgänge, 7–10 einer, bis 50, Stechen bei Gleichstand
- Karten: 4 verschiedene Bereiche, keine Zielfarbe doppelt
- **Gefilterte Ansicht**: Ratende und Bühne sehen vor dem Aufdecken weder `target` noch `card`
- Wiederverbinden mitten im Setzen: Person bleibt dran, Timer läuft weiter, Abwarten wie bei den anderen Spielen
